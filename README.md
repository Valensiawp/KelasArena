## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY`
3. Run the app:
   `npm run dev`

## Deploy
Untuk Setup awal **npm install firebase** Baru  **firebase login**
1. firebase init
2. npm run build
3. firebase deploy --only hosting
